# Projet de Surveillance de Batteries

## Introduction 

Ce repo a été réalisé dans le cadre d'un stage de 4ème année d'école d'ingénieurs à l'**École de Technologie Supérieure (ÉTS) de Montréal**, au sein du laboratoire **LACIME**, par un étudiant de **Polytech Grenoble**.
Si vous souhaitez avoir plus de détails sur le contenu de chaque projet merci de suivre les dossier projet_batterie et projet_salle_blanche.
Le dossier contient aussi tous les fichiers Kicad, Le dossier Kicad contient les évolutions des différentes cartes produites et la dernière version est celle à jour pour le projet batterie.
Le dossier Kicad esp maitre est le dossier principale pour le projet salle blanche.
